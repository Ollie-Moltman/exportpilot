1. What is an HS Code?

The Harmonized System (HS) code is a 6-digit international classification for traded products. It was developed by the World Customs Organization (WCO) and is used by 180+ countries, including India, to classify products for customs, duties, and trade statistics.

In India, HS codes are used by DGFT (Directorate General of Foreign Trade), CBIC (Central Board of Indirect Taxes), and customs authorities worldwide. The first 6 digits are globally standardized. Digits 7-8 are country-specific additions.

Why It Matters for Indian Exporters

The HS code determines your import duty rate in the destination country, whether your product qualifies for FTA benefits (like UAE CEPA or ASEAN FTA), and if any export restrictions apply. A wrong HS code can mean paying 10-30% more duty — or having your shipment held at customs.

2. How HS Code Structure Works

HS codes are hierarchical. Each additional digit narrows down the product classification:

2 digits

Chapter

Broadest category. There are 97 chapters (01-97). Example: Chapter 84 = Nuclear reactors, boilers, machinery.

4 digits

Heading

More specific group. Example: 8471 = Automatic data processing machines.

6 digits

Subheading

The internationally standardized code. Used globally for customs and FTAs. Example: 8471.30 = Portable digital computers.

8 digits

Indian Extra Detail (ITC(HS))

India-specific extension. Used by DGFT for export/import licensing. Example: 8471.30.10 = Notebooks/laptops.

Indian Exporters: Use 8 Digits for DGFT

For IEC applications, DGFT filings, and Indian customs, use the full 8-digit ITC(HS) code. For international customs and FTA duty calculations, the 6-digit global HS code is usually sufficient.

5. Costly HS Code Mistakes Indian Exporters Make

✗
Using a 4-digit HS code — Some exporters quote "8471" when they should use "8471.30.10" (notebooks). The 4-digit code is too broad and causes classification errors.
✗
Guessing instead of verifying — Two products can look identical but have different HS codes (e.g., men's vs women's t-shirts, raw cotton vs dyed cotton yarn). Always verify.
✗
Not checking the destination country — The same product can have different import duty rates in different countries. Always check the specific country's tariff.
✗
Missing FTA eligibility check — Your HS code determines whether your product qualifies for UAE CEPA, ASEAN FTA, or other preferential duties. The wrong HS code = no FTA benefits.
✗
Not updating when India revises codes — India updates ITC(HS) codes periodically. Using outdated codes can cause DGFT filing rejections. Check for updates annually.

Frequently Asked Questions

Is there a free HS code database for India?

Yes — CBIC's Tariff Finder (cbic.gov.in) and DGFT's ITC(HS) schedule are both free. However, ExportPilot's AI classifier is faster and easier for SMEs who aren't trade experts.

What's the difference between HS code and ITC(HS) code?

The first 6 digits are the global HS code (same worldwide). India adds 2 more digits to create the ITC(HS) code — this is India-specific and used for DGFT documentation. For export to international markets, the 6-digit HS code is what matters.

Can the same product have two different HS codes?

Yes. Subtle differences in material, use, or processing can change the HS code. For example: a cotton t-shirt (6109.10) vs a silk t-shirt (6209.90). The customs officer decides based on the actual product characteristics.

What happens if customs finds the wrong HS code?

Possible outcomes: customs delays, penalty/duty penalty (additional duty equal to the shortfall), goods being held or seized, or — if you underpaid duty — your importer facing a bill for the difference in the destination country.

How often do HS codes change?

The WCO updates the HS code system every 5 years (1996, 2002, 2007, 2012, 2017, 2022). India typically adopts the new version with a 1-2 year delay. Within those 5-year cycles, India's 8-digit ITC(HS) codes can be updated more frequently.
